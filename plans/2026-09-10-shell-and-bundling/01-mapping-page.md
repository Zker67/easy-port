# 映射页：可点链接、分区筛选与站点识别

> 状态：`[done]`

## 目标

用户原话：「点击映射里面的链接能直接访问，然后布局要灵活，提示直接放到底栏就行 /
映射里面要分为收藏，已开启，已关闭部分，还能进行筛选 / 映射中的网页要显示网页名字和图标」。

## 不变量

- 不变量 6：链接不得落盘、不得进日志与文档。可点击不改变这一点——只是把已在内存中的
  `publicUrl` 交给系统浏览器。
- 不变量 9（本轮新增）：站点探测只走 `127.0.0.1:<port>`。
- 已断开的映射仍留在映射页（ux-polish 之后确立的语义），本轮的分区不得让它提前消失。

## 实现清单

### 可点击的链接

`tunnel-card.tsx` 里链接由 `<span>` 改为 `<button type="button">`，
点击调用 `openInBrowser()`。保留 `.selectable` 与 `font-mono`，
使双击仍可选中文本复制——这是「点击即打开」带来的唯一交互损失，用 `title` 说明。

### 布局

- 外壳改为 `flex h-screen flex-col`，内容区 `flex-1 overflow-y-auto`，
  内层 `mx-auto w-full max-w-5xl`：窄窗口撑满，宽窗口不把卡片拉成长条。
- 常驻安全提示从内容区移到底栏（`App.tsx` 的 `<footer>`），不再占用列表空间。

### 分区与筛选

`mappings-page.tsx`：

- 三个分区：收藏 / 已开启 / 已关闭，只展示 `archived == false` 的条目。
- **收藏优先于运行状态**：收藏项即使已断开也留在收藏区。
  否则一条收藏映射会在开关时于两区之间跳动，用户找不到它。
- 筛选标签 `全部 / 收藏 / 已开启 / 已关闭`，搜索框匹配端口、备注、网页标题。
- 「归档已关闭」跳过收藏项，与分区规则一致。

后端新增 `set_favorite` command；`favorite` 落盘，用 `serde(default)` 兼容旧文件。
`registry::insert` 复用条目时保留旧的 `favorite`，避免重连后收藏丢失。

### 站点识别

新增 `src-tauri/src/tunnel/site.rs`：

- 隧道建立成功后 `tokio::spawn` 一次探测，不阻塞 `create_tunnel` 返回。
- 请求 `http://127.0.0.1:<port>`，取 `<title>`，再按 `<link rel="icon">` 或
  `/favicon.ico` 取图标转 data URI。
- 超时 2 秒；HTML 读取上限 64 KB，图标上限 128 KB。任一环节失败返回 `None`。
- `site` 初版**不落盘**，理由是「站点内容随时可能变，缓存旧标题只会误导」。
  **该决策已被推翻**，见 [03-site-persistence](./03-site-persistence.md)：
  用户指出启动后重新校验即可消除误导，同时保住「启动即有名字可认」。

卡片上图标与标题排在端口之前；有标题时端口降级为次要信息。

## 验收标准

- [x] 点击链接在系统浏览器打开；双击仍可选中文本。
- [x] 收藏项在收藏区，且开关状态变化时不跳区。
- [x] 搜索能命中端口、备注、网页标题三者。
- [x] 映射一个网页端口后，卡片出现标题与图标；映射一个非网页端口不受影响。
- [x] `cargo test --lib` 覆盖 HTML 标题与图标路径解析（4 项新增）。

## 回滚

前端改动集中在 `mappings-page.tsx` / `tunnel-card.tsx` / `App.tsx`；
后端 `site.rs` 可整体摘除，`Tunnel.site` 恒为 `None` 即退回原展示。
`favorite` 字段保留亦无害。
