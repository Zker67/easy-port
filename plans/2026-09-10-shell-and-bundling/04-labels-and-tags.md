# 备注与标签：端口成为持久单位

> 状态：`[done]`

## 目标

用户分两次提出：

1. 「映射的所有端口是一个单位，不是创建的时候才可以备注，随时都可以添加备注和标签」
   「端口列表里面的端口数字显示为一个特殊渲染的样式，只显示端口就行，不需要 localhost:」
2. 「备注和标签是两种类型，标签相当于人工分类，然后可以用标签筛选」

第一轮我把「备注和标签」当成了同一件事，只做了备注。用户指出后补做标签。
**这条要记住：用户并列说出两个名词时，先确认它们是不是同一个东西。**

## 方案确认

标签的实现方式先问了用户，确认为：**随用随建 + 并集筛选 + 无颜色**。

- 随用随建：没有独立的标签管理页，输入即创建；某标签的最后一个端口移除它后自动消失。
  比「预先建标签再挂」轻，符合本应用体量。
- 并集：选中多个标签时命中任一即显示。交集在标签少时几乎选不出东西。
- 无颜色：加颜色视觉分类效果更好，但要么随机分配、要么让用户选色，都会让交互变重。

## 不变量

- 不变量 6 不变：备注与标签都是用户输入的文本，落盘不含任何隧道 URL。
- `insert` 复用条目时必须保留 `tags`（同 `favorite`），否则重连会清掉分类。
- 新增字段一律 `serde(default)`，**不递增 version**，旧 `state.json` 可直接读。

## 备注与标签的分工

| | 备注 `label` | 标签 `tags` |
|---|---|---|
| 基数 | 每端口一条 | 每端口多个（上限 5） |
| 复用 | 不跨端口 | 跨端口复用，同名即同一分类 |
| 用途 | 自由文本，说明干什么用 | 人工分类，用于筛选 |
| 命令 | `set_label` | `set_tags`（覆盖式）、`all_tags` |
| 组件 | `label-editor.tsx` | `tag-editor.tsx` |

## 实现清单

### 端口渲染（`port-badge.tsx`）

去掉 `localhost:` 前缀——本应用映射的永远是本机端口，该前缀对每条都相同，不携带信息。
改为带边框的胶囊：等宽、`tabular-nums`、比正文大一号加粗，运行中用主题色实心。
保留一个弱化的 `:` 作为「这是端口」的视觉标记。端口同时挪到卡片最前面。

### 备注（`set_label`）

空串与全空白收敛为 `None`，否则落盘会出现 `"label": ""` 这种既非空又无内容的值。
就地编辑：Enter 保存、Esc 取消、失焦保存，用 `committed` ref 防止重复提交。

### 标签（`set_tags` / `all_tags`）

- 裁空白、丢空串、**大小写不敏感去重**（`Dev` 与 `dev` 视为同一个，保留首次写法）。
  否则筛选栏会出现一眼看去重复的标签。
- `MAX_TAGS_PER_TUNNEL = 5`，超出截断——防误操作（粘贴一整段文本）把卡片撑爆。
- `all_tags` **从条目现算**，不维护独立标签表。这是「随用随建」的关键：
  标签的存在性完全由「是否有端口在用」决定，不需要额外的清理逻辑。
- 前端 `useEffect` 把已消失的标签从选中集合里摘掉，
  否则会出现「选了个不存在的标签导致列表恒为空，且用户看不到那个按钮无从取消」。
- 空状态如实回报当前的筛选条件（关键词 + 标签），不然用户会以为映射丢了。
